# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** in full. The full text is available at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct.txt>

A summary in plain terms:

- Be respectful in issues, PRs, and Discussions.
- Disagree about technical decisions, not about people.
- No targeted personal attacks, demeaning comments, or off-topic provocations.

## Reporting

To report behavior that violates this Code of Conduct, contact the project owner privately:

- GitHub: open a [private vulnerability report](https://github.com/Achitokun14/clickup-tracker-standalone/security/advisories/new) (the same channel as security reports — it routes to the owner privately).
- Email: `<owner-email>` *(maintainer to fill in before publish)*.

All reports are read by the project owner only. Reporters' identities are kept confidential.

## Scope

This Code applies to all project spaces — issues, PRs, Discussions, commits, the wiki — and to public communication that represents the project elsewhere.

## Enforcement

The project owner is the sole enforcer for this small repo. Actions range from a private warning, to comment editing, to temporary or permanent ban from project spaces, depending on severity. Decisions are final at this scale; if you believe a decision was made in error, you may contact the owner once to request reconsideration.
